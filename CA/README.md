認証局 (CA) と証明書
========================================

https (mTLS) 通信を行うために認証局 (CA) と証明書を作成する。
作成済みのファイルはサンプルのため、検証目的でのみ使用可能。本番運用時は作り直すこと。


認証局 (CA) と証明書の作成
----------------------------------------

OpenSSL を使用して、ルート CA、中間 CA、サーバ証明書、クライアント証明書を作成する。


### 環境設定

デフォルトのインストールパスは `bat\define.bat` で設定済み。
環境に合わせて適宜変更する。

```dos
@REM  OpenSSL のパスを通す
set PATH=%PATH%;C:\Program Files\OpenSSL-Win64\bin
```


### 証明書の記載事項の変更

使用用途に合わせて証明書の記載事項を変更する。
証明書の記載事項と設定箇所は 設計情報 を参照。


### ルート CA、中間 CA の作成

`bat\gen_ca.bat` を実行する。


### サーバ証明書の作成

`bat\gen_server_crt.bat` を実行する。


### クライアント証明書の作成

`bat\gen_client_crt.bat` を実行する。

実行中に以下をキーボード入力する。

* Common Name
* パスワード
* パスワード（確認）


認証局 (CA) と証明書のインストール
----------------------------------------

### サーバ

特段の処置不要。
（証明書ファイルのパスを nginx で設定済み）

サーバ機からブラウザでアクセスする場合は、クライアント用の設定をすること。


### クライアント

#### ルート CA のインストール

* `root_ca.crt` をダブルクリック
* 「証明書のインストール」を押下する
* 保存場所「現在のユーザー」を選択して「次へ」を押下する
* 「証明書をすべて次のストアに配置する」を選択して「参照」を押下する
  * 「信頼されたルート証明機関」 を選択して「OK」を押下する
  * 「次へ」を押下する
* 「完了」を押下する
* セキュリティ警告画面が表示されたら「はい」を押下する
* 「正しくインポートされました。」が表示されたら「OK」を押下する


#### クライアント証明書 のインストール

* `client.pfx` をダブルクリック
* 保存場所「現在のユーザー」を選択して「次へ」を押下する
* 「次へ」を押下する
* パスワードを入力して「次へ」を押下する
* 「証明書をすべて次のストアに配置する」を選択して「参照」を押下する
  * 「個人」 を選択して「OK」を押下する
  * 「次へ」を押下する
* 「完了」を押下する
* 「正しくインポートされました。」が表示されたら「OK」を押下する

| L      | Locality (市区町村)             | -         | -                | Shinjuku-Ku     | -                  |

| OU     | Organizational Unit (部署名)    | -         | -                | Section X       | -                  |
| CN     | Common Name (コモンネーム)      | MyRootCA  | MyIntermediateCA | my-server.local | (keyboard)         |
| SAN(s) | Subject Alternative Name (別名) | -         | -                | my-server.local | -                  |

#### パスワード

クライアント証明書は発行先の本人以外が使えないようにパスワードによるロックが掛けられる。
そのパスワードはバッチファイルの実行中にキーボードで入力する。

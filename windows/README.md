Windows の設定変更
========================================

前提
----------------------------------------

* nginx が使用可能になっていること
* gitea が使用可能になっていること


nginx, gitea の自動起動
----------------------------------------

PC 起動時に nginx, gitea を自動起動する。

nginx は単体では Windows サービスに登録できない。
PC 起動時に実行開始するようにタスクスケジューラを設定する。
（WinSW を使えば Windows サービスに登録できるが、タスクスケジューラで代用可能なので使用しない）

gitea は Windows サービスに登録する。


### nginx をタスクスケジューラへ登録する

1. 「タスク スケジューラ」を開く。
2. 右側の操作パネルから 「タスクの作成」 を押下する。

    **全般 タブ**
    * 名前欄を入力する。（例： Nginx 自動起動）
    * セキュリティオプション
        * 「ユーザーがログオンしているかどうかにかかわらず実行する」を選択する。
        * 「最上位の特権で実行する」をチェックする。

    **トリガー タブ**
    * 「新規」 を押下する。
    * タスクの開始「スタートアップ時」（コンピューターの起動時）を選択する。
    * 詳細設定
        * 「有効」をチェックする。
    * 「OK」を押下する。

    **操作 タブ**
    * 「新規」 を押下する。
    * 操作「プログラムの開始」を選択する。
    * プログラム/スクリプトは参照から「 [/nginx/nginx-start.bat](/nginx/nginx-start.bat) 」を選択する。
        * 引数の追加（オプション） は空欄。
        * 開始（オプション） は空欄。
    * 「OK」を押下する。

    **条件 タブ**
    * 電源
        * 「コンピューターを AC 電源で使用している場合のみタスクを開始する」のチェックを外す。

    **設定 タブ**
    * 変更不要。

3. 「OK」を押下する。


### gitea を Windows サービスに登録する

**前提**  
説明は gitea を下記にインストールしている想定で記載している。

| ファイル  | パス                                        |
| :-------- | :------------------------------------------ |
| gitea.exe | C:\work\nginx-env\gitea\gitea.exe           |
| app.ini   | C:\work\nginx-env\gitea\custom\conf\app.ini |
| gitea.db  | C:\work\nginx-env\gitea\data\gitea.db       |

1. app.ini を変更する

    `RUN_USER` を PCホスト名 ＋ "$" にする。

    ```ini
    RUN_USER = my-server$
    ```

    （SQLite3 を使用している場合）  
    `PATH` を絶対パスにする。

    ```ini
    [database]
    PATH = C:\work\nginx-env\gitea\data\gitea.db
    ```

2. Windows サービスに登録する

    管理者権限でコマンドプロンプトを開いて下記のコマンドを実行する。

    ```dos
    sc.exe create gitea start= auto binPath= "\"C:\work\nginx-env\gitea\gitea.exe\" web --config \"C:\work\nginx-env\gitea\custom\conf\app.ini\""
    ```

    成功すれば下記が表示される。

    ```dos
    [SC] CreateService SUCCESS
    ```

    （参考情報）  
    Windows サービスから解除する場合は、下記のコマンドを実行する。

    ```dos
    sc.exe delete gitea
    ```


PC の自動起動、自動シャットダウン
----------------------------------------

サーバを 24 時間稼働する必要がない場合は、PCを定刻に起動・シャットダウンする。


### 高速スタートアップの無効化

自動起動を正確に行うためには、高速スタートアップを無効にしておくと無難。

1. 「コントロール パネル」を開く
2. 右上の表示方法「大きいアイコン」または「小さいアイコン」を選択する。
3. 「電源オプション」を押下する。
4. 左側のメニューから「電源ボタンの動作を選択する」を押下する。
5. 「🛡️現在利用可能ではない設定を変更します」を押下する。
6. 「高速スタートアップを有効にする（推奨）」のチェックを外す。
7. 「変更の保存」を押下する。


### 定刻に PC を起動する

BIOS に定刻電源オンの設定をする。

1. BIOS を開く。

    1. コマンドプロンプトで `shutdown -r -o -t 0` を実行する。（注意：直ちに再起動を開始する）
    2. 「トラブルシューティング」を選択する。
    3. 「詳細オプション」を選択する。
    4. 「UEFI ファームウェアの設定」を選択する。
    5. 「再起動」を押下する。

2. 起動時刻を設定する。

    1. BIOSの設定画面で、「Resume By RTC Alarm」、「自動スケジュール］、「スケジュールされた電源投入」などの項目を探す。
    2. 起動時刻を設定する。
    3. 設定を保存して Windows を起動する。


### 定刻に PC をシャットダウンする

タスク スケジューラ に定刻シャットダウンのタスクを登録する。

1. 「タスク スケジューラ」を開く。
2. 右側の操作パネルから 「タスクの作成」 を押下する。

    **全般 タブ**
    * 名前欄を入力する。（例： ｘｘ時にシャットダウン）
    * セキュリティオプション
        * 「ユーザーがログオンしているかどうかにかかわらず実行する」を選択する。

    **トリガー タブ**
    * 「新規」 を押下する。
    * タスクの開始「スケジュールに従う」を選択する。
        * シャットダウンの頻度を入力する。
    * 詳細設定
        * 「有効」をチェックする。
    * 「OK」を押下する。

    **操作 タブ**
    * 「新規」 を押下する。
    * 操作「プログラムの開始」を選択する。
    * プログラム/スクリプト欄に「shutdown」を入力する。
    * 引数の追加欄に「/s /t 300 /c "5 分後にシャットダウンします。中止する場合は「shutdown /a」を実行してください。"」を入力する。
    * 「OK」を押下する。

    | オプション      |  説明                                                       |
    | :-------------- | :---------------------------------------------------------- |
    | `/s`            | コンピューターをシャットダウンします。                      |
    | `/t 300`        | シャットダウンまでのタイムアウト期間を 300 秒に設定します。 |
    | `/c "コメント"` | 再起動またはシャットダウンの理由にコメントを付けます。      |


    **条件 タブ**
    * 電源
        * 「コンピューターを AC 電源で使用している場合のみタスクを開始する」のチェックを外す。

    **設定 タブ**
    * 変更不要。

3. 「OK」を押下する。


### Wake On Lan を有効化する

自動起動に失敗した場合は Wake On Lan で起動する。

設定方法は省略。


#### Wake On Lan による起動

1. [boot_wakeonlan.bat](/windows/bat/boot_wakeonlan.bat) の変数 `MAC_ADDRESS` を起動する PC のアドレスに変更する。
2. [boot_wakeonlan.bat](/windows/bat/boot_wakeonlan.bat) を実行する。
